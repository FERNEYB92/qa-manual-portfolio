# 🧪 Portfolio de QA & Automation Engineering - Ferney Bautista

¡Bienvenido a mi portafolio profesional de Quality Assurance! Este repositorio contiene evidencia práctica de proyectos de pruebas de software manuales, pruebas de API, automatización Web E2E e Integración Continua (CI/CD).

---

## 🚀 Habilidades Técnicas
* **Pruebas Manuales:** Diseños de casos de prueba, matrices de trazabilidad, reporte de bugs, historias de usuario y metodologías ágiles (Scrum).
* **API Testing:** Postman (colecciones, assertions en JavaScript, variables de entorno y runners).
* **Automation Frameworks:** Playwright (JavaScript) & Cypress.
* **CI/CD:** GitHub Actions (pipelines automatizados en entornos Linux con generación de artefactos HTML).
* **Control de Versiones:** Git, GitHub, Git Bash.
* **Gestión & Documentación:** Trello, Jira (conceptos), Markdown.

text

---

## ⚡ Integración Continua (CI/CD)
El proyecto cuenta con un workflow en **GitHub Actions** (`.github/workflows/playwright.yml`) que se ejecuta automáticamente ante cada `push` o `pull_request` a la rama principal (`main`), garantizando que la suite de pruebas E2E en Playwright se valide en un runner remoto `ubuntu-latest`.
